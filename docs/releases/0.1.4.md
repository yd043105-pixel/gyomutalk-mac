# 교무톡 0.1.4

- 수업 교체를 Windows처럼 한 주 전체 시간표에서 합니다. 수업을 누르면 바꿀 수 있는 칸이 초록색으로 보이고, 같은 묶음수업은 같은 색입니다.
- 묶음수업을 학년 → 과목 → 분반 순으로 고르고, 시간표 첫 화면과 파일 제출 현황을 Windows와 같은 모양으로 맞췄습니다.
- 서버에서 지워진 메시지 제목을 이 Mac의 사본에서 다시 보여 줍니다.

이번 버전은 학교 서버와 교직원용 메신저 중 어느 쪽을 먼저 업데이트해도 됩니다.

Mac용은 Apple 정식 서명과 공증 전 시험용 사전 릴리즈입니다. GitHub에서 기기에 맞는 ZIP을 내려받아 설치하세요.

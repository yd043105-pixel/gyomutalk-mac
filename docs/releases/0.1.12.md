# 교무톡 0.1.12

- 다음 주 수업과 교체: 수업 교체 판에서 내 수업을 고른 채 ‘›’로 다음 주로 넘기면 고른 수업이 위쪽에 ‘옮길 수업 · …’으로 따라가고, 그 주에서 바꿀 수 있는 수업이 초록색으로 보입니다. 시간표 담당자는 ‘교체할 수 있는 범위’(같은 주만 ~ 4주 뒤까지, 처음은 다음 주까지)를 고르고, 다른 주와 바꾼 신청에는 ‘다른 주와 교체’ 표시가 붙습니다.
- 받은 파일: 누르면 묻지 않고 홈 폴더의 문서/GyomutalkFiles에 저장되고, 같은 이름이 있으면 ‘이름 (2)’로 저장됩니다. 오른쪽 클릭하면 ‘지정된 폴더에 다운로드’(저장 위치 표시), ‘다른 이름으로 저장’, ‘받은 파일 폴더 열기’가 나옵니다.
- 자동 로그인이 처음부터 켜져 있습니다. 여러 사람이 함께 쓰는 컴퓨터라면 로그인 화면에서 끄세요.

다음 주 수업과 교체는 학교 서버가 0.1.12여야 쓸 수 있습니다.

Mac용은 Apple 정식 서명과 공증 전 시험용 사전 릴리즈입니다. 자동 업데이트와 로그인 시 자동 실행은 아직 없습니다. GitHub에서 기기에 맞는 ZIP을 내려받아 설치하세요.

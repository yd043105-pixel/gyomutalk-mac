# 교무톡 0.1.11

- Mac 교무톡에 채팅, 설문, 수강신청(교육과정 담당)이 생겼습니다. 새 메시지·채팅·설문·시간표 변경이 macOS 알림으로 오고, 왼쪽 메뉴에 안 읽은 개수가 보입니다. ‘내 정보’에서 알림 소리 끄기와 방해금지를 켤 수 있습니다.
- 새 메시지에서 받는 사람 이름 입력, 붙여넣기 버튼으로 복사한 사진·파일 첨부, 예약 전송과 예약 목록, 임시저장(창을 닫으면 자동 저장), 보내기 전 말투 점검, AI로 다듬기를 씁니다.
- 조직도 즐겨찾기·작게 보기, 메시지에서 찾은 할 일 추천, 수업 교체의 연쇄 교체·수업 불가 시간 고르기·교체 도우미가 생겼습니다. 시간표 담당자는 교체 신청을 바로 승인하고, 시간표를 올릴 때 이름이 같은 선생님을 과목마다 고릅니다.
- 원격지원, 글자 서식(굵게·색), 화면 색 바꾸기, 수강신청의 함께 듣는 학생 수·분반 편성·확인서 인쇄는 Windows에서 하세요.

학교 서버와 교직원 PC를 어느 쪽부터 업데이트해도 됩니다.

Mac용은 Apple 정식 서명과 공증 전 시험용 사전 릴리즈입니다. GitHub에서 기기에 맞는 ZIP을 내려받아 설치하세요.
